## Instructions for Running Locally

### Install Dependencies

`npm install`

### Build

`npm run build`

### Update and Clear Local DB

`npm run db:migrate:local` then `npm run db:reset:local`

### Start Server

`npm run dev:pages` and hit `b` to open up the window automatically
